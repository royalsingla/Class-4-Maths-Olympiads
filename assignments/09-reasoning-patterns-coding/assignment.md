# Week 9 — Reasoning: Patterns, Analogy, Classification & Coding-Decoding

15 questions, 4-option MCQ, untimed.

---

**Q1.** Find the odd one out:
A) Dog  B) Cat  C) Cow  D) Chair

**Q2.** Apple is to Fruit as Carrot is to ___.
A) Animal  B) Vegetable  C) Flower  D) Tree

**Q3.** Find the odd one out:
A) 2  B) 4  C) 7  D) 8

**Q4.** Book is to Read as Song is to ___.
A) Sing  B) Write  C) Draw  D) Eat

**Q5.** In a certain code, each letter of a word is moved 2 steps forward in the alphabet (A→C, B→D, …). Using this rule, DOG is written as FQI. How is CAT written in the same code?
A) ECV  B) EDW  C) DCW  D) ECW

**Q6.** In a certain code, each letter is moved 1 step forward (A→B, B→C, …). Using this rule, MANGO is written as NBOHP. How is APPLE written in the same code?
A) BQQMF  B) BPPMF  C) BQQME  D) CQQMF

**Q7.** Complete the series: A, C, E, G, ___
A) H  B) I  C) J  D) K

**Q8.** Complete the series: Z, X, V, T, ___
A) R  B) S  C) Q  D) P

**Q9.** Find the odd one out:
A) Circle  B) Oval  C) Cube  D) Square

**Q10.** Find the odd one out:
A) Rose  B) Lily  C) Lotus  D) Mango

**Q11.** Find the number that does not belong with the rest:
A) 9  B) 16  C) 20  D) 25

**Q12.** If each letter of a word is replaced by its position number in the alphabet (A=1, B=2, …), CAT is written as 3-1-20. How is PEN written using the same rule?
A) 16-5-14  B) 16-5-13  C) 15-5-14  D) 16-4-14

**Q13.** Complete the pattern: 2, 4, 6, 8, ___, 12
A) 9  B) 10  C) 11  D) 14

**Q14.** In a code, each letter is moved 1 step forward (A→B, B→C, …). Using this rule, TABLE is written as UBCMF. How is CHAIR written in the same code?
A) DIBJS  B) DIBIS  C) DJBJS  D) DIBJT

**Q15.** In each of these numbers, the sum of the digits equals 3, except one. Find the odd one out:
A) 12  B) 21  C) 30  D) 23
