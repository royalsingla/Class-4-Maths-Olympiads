# Assignments

Topic-wise practice worksheets, one folder per week of the plan in
`../docs/03-practice-plan.md`. Each folder (once built) contains:

- `assignment.md` — the questions (4-option MCQ, Class 4 difficulty,
  mixing direct computation with word-problem/Everyday-Maths style framing)
- `answer-key.md` — correct options with a short worked explanation each

and `12-math-kangaroo-stretch/` each ship an `images/` folder of SVG
diagrams referenced from their `assignment.md`.

## Diagram-based question types

Mirror images, embedded figures, and geometrical-solid recognition are
inherently visual Section‑1 (Logical Reasoning) sub-topics. Rather than
describing them in text, `10-reasoning-direction-figures/images/` has an
SVG diagram for each question:

- **Mirror images** — the original figure plus 4 candidate reflections (one
  correctly flipped left-right, the other three are unchanged / flipped
  upside-down / rotated 180° — classic distractors). The correct option is
  generated by an exact `scale(-1,1)` transform, not hand-drawn, so it's
  guaranteed accurate.
- **Embedded figures** — a composite figure made of two overlapping shapes;
  find which of 4 candidate shapes is traceable inside it.
- **Geometrical solids** — a drawn cube, cone, and cylinder, each with a
  question about its name or face count.

`08-data-handling/images/` similarly has a real SVG pictograph and bar
graph (rather than an emoji/markdown-table stand-in) for its data-handling
questions.

`12-math-kangaroo-stretch/images/` has 7 more SVGs for its puzzle
questions — shape-counting figures, a mirror-image puzzle (same
guaranteed-correct transform technique as above), a balance-scale
illustration, a grid for path-counting, a shaded-fraction figure, and a
labelled cube net.
