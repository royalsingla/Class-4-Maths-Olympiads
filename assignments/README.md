# Assignments

Topic-wise practice worksheets, one folder per week of the plan in
`../docs/03-practice-plan.md`. Each folder (once built) contains:

- `assignment.md` — the questions (4-option MCQ, Class 4 difficulty,
  mixing direct computation with word-problem/Everyday-Maths style framing)
- `answer-key.md` — correct options with a short worked explanation each

week) and follow the exact question-count/format of `01-number-sense/` —
add them in the same two-file (`assignment.md` + `answer-key.md`) shape as
you work through the plan.

## A note on diagram-based question types

Some Section‑1 (Logical Reasoning) sub-topics are inherently visual and
can't be faithfully represented in plain Markdown text:

- **Mirror images** (which figure is the mirror reflection of a given one)
- **Embedded figures** (spot the hidden shape inside a larger figure)
- **Geometrical shapes and solids** (nets, 3-D solid recognition)

`10-reasoning-direction-figures/`, when built, will cover the *textual*
reasoning skills (ranking, direction sense, days & dates) in full, and will
call out these three diagram-only sub-topics explicitly so they can be
supplemented from an image-based worksheet or workbook rather than silently
skipped.
