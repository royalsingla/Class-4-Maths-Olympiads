# Week 1 — Number Sense & Numerals — Answer Key

**Q1. D) 7000** — In 57,342 the digits are 5‑7‑3‑4‑2 (ten-thousands,
thousands, hundreds, tens, ones). 7 sits in the thousands place → 7 × 1000 = 7000.

**Q2. A) Sixty-eight thousand two hundred five** — 68,205 reads as
68-thousand, 205.

**Q3. B) 90000 + 3000 + 40 + 7** — 93,047: 9=ten-thousands(90000),
3=thousands(3000), 0=hundreds(0 — skipped), 4=tens(40), 7=ones(7).

**Q4. B) 45,986** — Comparing the last three digits once "45," matches:
698 vs 986 vs 869 vs 689 → 986 is largest.

**Q5. C) 71,999** — It's the only one starting 71, (the rest start 72,),
so it's smaller than all of them.

**Q6. A) 34125, 34251, 34512, 34521** — Smallest to largest by comparing
digit by digit from the left.

**Q7. B) 70000** — Successor = number + 1; 69,999 + 1 = 70,000.

**Q8. A) 49999** — Predecessor = number − 1; 50,000 − 1 = 49,999.

**Q9. A) 6700** — Rounding to the nearest hundred looks at the tens digit
(4); since 4 < 5, round down: 6,742 → 6,700.

**Q10. A) 3000** — Rounding to the nearest thousand looks at the hundreds
digit (2); since 2 < 5, round down: 3,256 → 3,000.

**Q11. A) XLVII** — 47 = 40 (XL) + 7 (VII) = XLVII.

**Q12. B) 74** — LXXIV = L(50) + X(10) + X(10) + IV(4) = 74.

**Q13. C) 25** — The pattern adds 5 each time: 5, 10, 15, 20, 25, 30.

**Q14. A) 54** — The pattern subtracts 9 each time: 81, 72, 63, 54, 45.

**Q15. B) 100** — 1,00,000 ÷ 1,000 = 100.
