# Incomplete Pattern — Answer Key

1. **C** — Each row shows 1, 2, 3 dots left to right (count increases by 1 each column). The missing cell needs 3 dots.
2. **A** — Each row shows the arrow turning 90° clockwise each column: up → right → down. The missing cell needs the arrow pointing down.
3. **C** — Each row shows a shape gaining one side each column: 3 sides, 4 sides, 5 sides. The missing cell needs a 5-sided shape (pentagon).
4. **B** — Each row shows the square getting more shaded: empty, half, full. The missing cell needs a fully-shaded square.
5. **A** — Each row shows 1, 2, 3 stars left to right. The missing cell needs 3 stars.
6. **D** — Each row shows 1, 2, 3 lines left to right. The missing cell needs 3 lines.
7. **B** — Each row shows the square growing bigger each column: small, medium, large. The missing cell needs the largest square.
8. **B** — Each row shows a shape LOSING one side each column: 6 sides, 5 sides, 4 sides. The missing cell needs a 4-sided shape.
9. **C** — Each row alternates the arrow direction: up, down, up. It is NOT always increasing — it flips back. The missing cell needs the arrow pointing up again.
10. **B** — Each row alternates the triangle's direction: pointing up, pointing down, pointing up. The missing cell needs the triangle pointing up again.
11. **A** — Each row shows the square getting smaller each column: large, medium, small. The missing cell needs the smallest square.
12. **A** — Each row shows the square getting LESS shaded each column: full, half, empty. The missing cell needs an empty (unshaded) square.
13. **D** — Each row shows the dot count jumping by 2 each column: 1, 3, 5. The missing cell needs 5 dots.
14. **A** — Each row shows the line count going DOWN each column: 3, 2, 1. The missing cell needs just 1 line.
15. **C** — Each row shows a solid shape gaining one side each column: 3 sides, 4 sides, 5 sides. The missing cell needs a solid 5-sided shape.

---

**How to use this:** cover the options and work out what the pattern is doing (growing, shrinking, rotating, alternating...) before looking at A–D. Always check the rule against BOTH complete rows, not just one.
