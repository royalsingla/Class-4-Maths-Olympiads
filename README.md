# Class 4 Maths Olympiad — Prep Kit

A self-contained practice kit for Class 4 (age 9–10) Mathematics Olympiad exams —
SOF‑IMO, Silverzone iOM, Unified Council UIMO, and similar school-level olympiads.
It covers the syllabus, the exact exam pattern, a week-by-week practice plan, topic
worksheets, and full-length timed sample papers.

## Primary target exam

The pattern and worksheets are built against **SOF International Mathematics
Olympiad (IMO), Class 4** — the most widely taken olympiad of this type — because
its 4‑section structure (Logical Reasoning / Mathematical Reasoning / Everyday
Mathematics / Achievers) is a superset of what Silverzone iOM and UIMO test.
Topic overlap with those two is mapped out in [`docs/01-syllabus.md`](docs/01-syllabus.md),
so the same worksheets double as prep for any of the three.

## How to use this

1. Read `docs/01-syllabus.md` and `docs/02-exam-pattern.md` once, so you know
   what "done" looks like.
2. Follow `docs/03-practice-plan.md` week by week — it tells you which
   assignment to do and when to attempt a timed sample paper.
3. Every assignment and sample paper is self-contained: questions first,
   answer key (with short explanations) in a separate file, so you can
   mark your own work.
4. Sample papers are meant to be done **strictly timed** (60 minutes, no
   calculator) to build real exam pace.
